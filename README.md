# 🩸 악인 온라인 (Akin Online)

> **"누가 선인이고, 누가 악인인가?"**  
> 심리적 긴장감과 배틀로얄 룰이 결합된 실시간 멀티플레이어 보드게임 웹 애플리케이션입니다.

---

## 📖 게임 소개

**악인(AKIN)** 은 플레이어들이 카드를 뽑고 상호작용하며 생존을 도모하는 심리 전략 배틀로얄 게임입니다.  
플레이어는 자신이 획득한 카드에 따라 **선인(Good)** 혹은 **악인(Evil)** 으로 성향이 변화하며, 상대방의 성향과 패를 추리하여 최후의 승자가 되어야 합니다.

### 🌟 핵심 게임 시스템
1. **실시간 멀티플레이어**: Socket.IO 기반 실시간 상태 동기화 및 턴 타이머 시스템
2. **동적 성향 변화 (선인 / 악인)**:
   - 악의 수치 2포인트 이상 시 **악인(🩸)** 으로 전환
   - `[선의]`, `[교화의 창]` 등 다양한 카드를 통한 악의 제어 및 반전
3. **풍부한 카드 카탈로그 (총 62종)**:
   - 🗡️ **무기 카드**: 황금칼, 필멸의 창, 교화의 창, 누군가의 뼈 등
   - 🛡️ **방패 카드**: 황금 방패, 거울 방패(반사/랠리), 수호천사(구호 방어), 누군가의 방패 등
   - 🧪 **아이템 카드**: 침묵, 인간 방패, 긴급탈출키트, 선의, 독재, 스캐빈져, 인연의 끈 등
   - 👑 **보물 카드**: 성배, 골든 레코드, 부처님 손바닥 등
   - 🩸 **악의 카드**: 일반 악의, 짙은 악의, 상처, 코즈믹 호러, 흑역사 등
   - 📜 **이벤트 카드**: 피바라기, 마육검(악의 경매), 악마의 고해소, 천사의 심판대, 구덩이(투표), 예언, 난투, 룰렛, 선물, 인체 연성, 뒤바뀐 영혼, 눈 없는 괴물 등
4. **인터랙티브 UI / UX**:
   - God Field 스타일의 직관적인 핸드 및 카드 슬롯 인터페이스
   - 채팅 및 게임 로그 내 카드명 카테고리 색상 하이라이트 & 마우스 호버/클릭 시 카드 상세 정보 즉시 확인
   - 사망 후에도 유령(👻) 상태로 자유로운 대화 및 유령 전용 이벤트(카르마, 폴터가이스트) 참여 가능

## 🛠️ 기술 스택

### Frontend (`client/`)
- **Framework**: React 19, TypeScript
- **Bundler**: Vite
- **Real-time**: Socket.IO Client
- **Styling**: Modern Vanilla CSS, CSS Grid/Flexbox, Glassmorphism UI

### Backend (`server/`)
- **Runtime**: Node.js, Express
- **Language**: TypeScript
- **Real-time**: Socket.IO Server
- **Architecture**: Room 기반 인메모리 배틀로얄 게임 엔진 (`GameRoom.ts`)

## 🚀 빠른 시작 가이드 (Getting Started)

### 1. 저장소 클론
```bash
git clone <your-repository-url>
cd akin
```

### 2. 서버 실행
```bash
cd server
npm install
npm run dev # 또는 npm run build && npm run start
```
> 서버는 기본적으로 `http://localhost:4000` 포트에서 실행됩니다.

### 3. 클라이언트 실행
```bash
cd ../client
npm install
npm run dev
```
> 브라우저에서 `http://localhost:5173` 으로 접속합니다.
